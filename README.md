# Spark 终端工具

基于 **Wails v3**（Go + Vue3 + Element Plus + xterm.js）的桌面终端工具，集成：

- **SSH 终端**：多标签页交互式终端（PTY），支持密码 / 私钥认证、终端尺寸自适应、会话结束提示与重连
- **SFTP 文件管理**：基于 SSH 的文件管理，双栏（本地 ⇄ 远程），支持浏览、上传、下载、新建目录、重命名、删除（递归）、修改权限
- **FTP / FTPS 文件管理**：与 SFTP 一致的双栏文件管理，支持显式 TLS（FTPS）、递归删除
- **文件搜索与编辑**：本地 / SFTP / FTP 均支持按**文件名**或**文件内容**递归搜索当前目录及全部子目录；双击文件在内置 **CodeMirror** 编辑器打开并可直接保存回远端/本地
- **文档管理**：类 VS Code 的文档模块——左侧目录树、右侧内容编辑，文档列表与内容全部存数据库；支持新建 / 重命名 / 删除 / 拖拽移动、按文件名或内容搜索
- **站点管理**：类文档管理的目录树（多级文件夹 + 站点）；每个站点挂多个链接，每个链接下挂多个账号密码（加密存储、一键复制）；点击链接在右侧**内嵌浏览器**打开、多站点**标签切换**，支持前进/后退/刷新，可一键转到系统浏览器
- **连接管理**：SSH / FTP 连接信息持久化保存到本地 SQLite，一键打开终端 / SFTP / FTP

## 技术栈

| 层 | 技术 |
| --- | --- |
| 桌面框架 | [Wails v3](https://v3.wails.io/)（WebView2 / WKWebView / WebKitGTK） |
| 后端 | Go 1.26，`golang.org/x/crypto/ssh`、`github.com/pkg/sftp`、`github.com/jlaffaye/ftp`、GORM + SQLite |
| 前端 | Vue 3 + TypeScript + Vite + Element Plus（暗色主题）+ xterm.js + CodeMirror 6（内置编辑器） |

## 目录结构

```
├── main.go                    # 应用入口：注册服务与事件
├── app/
│   ├── model/                 # GORM 模型（SavedConnection / DocNode 等）
│   └── service/
│       ├── terminal/          # SSH 终端会话（PTY、resize、输入输出事件）
│       ├── sftp/              # SFTP 文件操作（目录递归、断点续传）
│       ├── ftp/               # FTP/FTPS 文件操作（目录递归、REST 续传）
│       ├── documents/         # 文档管理（树 CRUD、内容存取、搜索）
│       ├── sites/             # 站点管理（站点/链接/账号 CRUD、打开链接）
│       ├── connections/       # 已保存连接 CRUD
│       ├── local/             # 本地文件列表 + 原生文件对话框
│       ├── hostkeys/          # SSH 主机密钥校验与 known_hosts 管理
│       ├── secure/            # 凭据 AES-256-GCM 加密（机器绑定密钥）
│       ├── sshlib/            # SSH 认证配置、known_hosts 校验
│       ├── fileutil/          # 搜索/编辑器共享工具（二进制判断、匹配）
│       └── types/             # 前后端共享 DTO
└── frontend/
    ├── src/
    │   ├── views/             # ConnectionsView / TerminalView / FileManagerView / DocumentsView / SitesView
    │   ├── components/        # TerminalPane / FilePanel / CodeEditor / TextEditor / SearchDialog ...
    │   ├── stores/            # Pinia：连接、终端会话、传输队列
    │   └── utils/             # wails 绑定出口、文件面板适配器
    └── bindings/              # wails3 generate bindings 生成的 TS 绑定（勿手改）
```

## 开发

前置要求：Go 1.24+、Node.js 18+、[wails3 CLI](https://v3.wails.io/)、[go-task](https://taskfile.dev)（`go install github.com/go-task/task/v3/cmd/task@latest`）。

```bash
# 安装前端依赖
cd frontend && npm install && cd ..

# 后端代码有变动时重新生成 TS 绑定（服务方法签名变化后必做；构建任务会自动执行）
wails3 generate bindings -d frontend/bindings -clean -ts -i . ./app/service/...

# 开发模式（前端热更新）
wails3 task dev

# 生产构建（可指定版本号，默认 1.0.0，注入到应用内"关于"）
wails3 task build VERSION=1.0.0

# 仅验证后端编译
go build .
```

## 版本管理 / 发布

- 版本号在 `build/windows/Taskfile.yml`（及 linux/darwin）的 `VERSION` 变量，构建时通过 ldflags 注入，应用内「设置 → 关于」显示当前版本
- Windows 可执行文件的版本信息在 `build/windows/info.json`（打包发布时由工作流按 tag 自动改写）
- **GitHub 自动发布**：推送 `v*` 标签（如 `v1.0.0`）触发 `.github/workflows/release.yml`，自动构建 Windows / Linux / macOS 三平台产物并发布到 GitHub Release：
  ```bash
  git tag v1.0.0 && git push origin v1.0.0
  ```
- 每次提交/PR 由 `.github/workflows/ci.yml` 做完整构建 + 后端测试，防止破坏构建

## 使用说明

1. **连接管理**页：新建/编辑/删除保存的 SSH、FTP 连接；每行可快速打开终端、SFTP 或 FTP；
   - 「主机密钥」按钮可查看 / 删除已信任的主机密钥（known_hosts）。
2. **SSH 终端**页：点击 `+` 新建会话，支持多标签；粘贴私钥内容即可用密钥登录；关闭标签或会话退出会自动断开；
   - 终端右键菜单：复制 / 粘贴 / 全选 / 清屏（剪贴板走系统 API）；终端内快捷键：**Ctrl+Shift+C 复制 / Ctrl+Shift+V 粘贴**（亦支持 Ctrl+Insert / Shift+Insert），Ctrl+C 保留为中断信号，Ctrl+V 走系统原生粘贴
   - 标签栏右侧的 ⓘ 按钮可展开**右侧信息面板**，三个视图可切换：
     - **服务器信息**：主机名 / 操作系统 / 内核 / 架构 / 运行时间 / CPU 型号与核心数 / 负载 / 内存占用 / 磁盘占用，带刷新按钮（读取 /proc 与 df，非 Linux 服务器给出提示）
     - **进程管理**：进程列表（CPU / 内存 / 状态），按 CPU 排序，可搜索、点击进程一键强制终止；每 5 秒自动刷新（切走自动暂停）
     - **自定义命令**：保存常用命令（**存数据库**），一键发送；命令直接写入左侧终端执行（如手动输入后回车），并保留发送记录；顶部输入框可临时发送任意命令
   - 首次连接新主机时会校验主机密钥并弹窗确认指纹（SHA256），信任后自动写入 known_hosts，之后连接不再提示；
   - 密钥不匹配（可能中间人攻击）会给出新旧指纹对比，确认无风险后可更新密钥继续。
3. **SFTP / FTP 文件**页：选择已保存连接（或新建）后点击连接；左侧本地、右侧远程；
   - `⇧ 上传选中`：把本地选中的**文件或目录（递归）**传到远程当前目录——支持**复选框多选**批量上传，全部完成后统一提示"全部上传完成（N 项）"；系统对话框多选上传同样汇总提示
   - `⇩ 下载选中`：把远程选中的**文件或目录（递归）**下载到本地当前目录
   - `上传`：通过系统文件对话框多选文件上传；`上传目录`：选择整个目录递归上传
   - **拖拽传输**：按住条目（名称区域）拖到另一侧面板即可上传/下载（支持目录递归）；也可以直接从资源管理器把文件拖进远程面板上传
   - **右键菜单**：右键空白处操作当前目录（上传文件 / 上传目录 / 新建目录 / 刷新 / 返回上级 / 主目录）；右键文件或目录操作条目（上传 / 下载 / 打开 / 重命名 / 修改权限 / 删除）；浏览器自带右键菜单已全局禁用
   - **目录收藏**：每个面板标题栏右侧的 ★ 收藏按钮，对应面板自身——本地面板收藏本机目录，远程面板收藏服务器目录（存数据库，远程按连接区分）；点收藏项即跳转，可删除
   - 工具栏支持新建目录、重命名、删除（目录递归删除）、修改权限（仅 SFTP）
   - **断点续传**：文件传输中断后再次传输会自动从已完成的偏移继续（SFTP 直接支持；FTP 依赖服务器 REST 命令，不支持时自动退回整文件传输）
   - **搜索**：每个面板路径栏右侧的 🔍 按钮，可**按文件名**或**按文件内容**递归搜索当前目录及全部子目录（内容搜索会跳过二进制文件与超过 10MB 的文件）；双击结果目录进入、双击结果文件在编辑器中打开（内容搜索命中会定位到对应行）
   - **内置编辑器**：双击文件（或右键「打开（编辑）」）在 CodeMirror 编辑器中打开并编辑，`Ctrl+S` 保存回远端/本地；打开时会拒绝二进制文件与超过 20MB 的文件
   - 双击目录进入，路径栏可手动输入后回车跳转
   - 底部传输队列实时显示上传/下载进度
4. **文档管理**页：类 VS Code 的文档模块，左侧目录树、右侧内容编辑，**列表与内容都存数据库**；
   - 工具栏：新建文件 / 新建文件夹 / 重命名 / 删除；右键树节点也可新建（目录内）、重命名、删除
   - **拖拽移动**：把节点拖到目录上（或目录前/后）调整层级与顺序
   - **编辑器**：基于 CodeMirror，按文件扩展名自动语法高亮，支持搜索（Ctrl+F）、`Ctrl+S` 保存；切换文件时未保存会提示
   - **搜索**：顶部搜索框可**按文件名**或**按文件内容**搜索全部文档，双击结果打开并定位到命中行
   - 与 SFTP / FTP 文件页共用同一套 CodeMirror 编辑器组件
5. **站点管理**页：类文档管理的目录树「多级文件夹 + 站点」，全部存数据库；
   - 左侧树：多级文件夹 + 站点，支持新建文件夹 / 新建站点、重命名、删除、**拖拽移动**（右键节点或空白处也可操作）
   - 选中站点后右侧分左右两栏：左栏该站点的**链接**（名称可留空，留空时默认取域名；地址 + 备注）；右栏直接显示所选链接的**账号**（账号 + 密码 + 备注），选中链接即切换账号（默认选中第一个链接），无需再点展开；密码**加密存储**，可一键复制账号 / 密码、显示/隐藏密码
   - **内嵌打开**：点击链接右侧 ↗ 在右侧**内嵌浏览器**打开，多个站点/链接以**标签页**切换（标签可关闭）；未写协议时自动补 `https://`
   - 每个标签顶部工具栏有**后退 / 前进 / 刷新**按钮、**可编辑的地址栏**（输入后回车跳转）与「在浏览器打开」按钮（后者可一键转到系统默认浏览器；部分站点禁止被 iframe 嵌入会显示空白，此时请用此按钮）

## 存储与同步

- **存储后端可切换**（设置 → 数据库）：默认本地 SQLite，设置后才使用远程库；支持 **MySQL / PostgreSQL / SQL Server / Oracle**（Oracle 用纯 Go 驱动 `godoes/gorm-oracle`，无需 C 编译）
- 连接、收藏、自定义命令、配置与快捷键都保存在所选数据库中；**数据库连接配置永久保存在本机**（`%APPDATA%\spark\dbconfig.json`），重启自动使用、无需重新设置；远程连接超时 10 秒自动放弃
- **多机同步**：多台机器配置**同一个远程数据库**即可开箱即用——连接密码的加密密钥由数据库连接信息自动派生，能连接同一数据库的机器自动获得同一密钥并解密，无需任何额外设置（能连库即视为已授权）；「同步密钥」仅作为可选的额外加固（所有机器填完全相同密钥时才生效）
- **切换语义**：目标库为空 → 自动把当前数据迁移过去（凭据按新密钥重新加密）；目标库已有数据（如第二台机器加入共享库）→ 只切换连接、**不覆盖目标数据**；切换后连接立即重置生效

## 安全说明

- **连接保活**：SSH / SFTP 连接每 20 秒发送 SSH keepalive，FTP 每 20 秒发送 NOOP，防止空闲超时（服务器 / NAT / 防火墙）自动断开；连续 3 次探测失败判定连接死亡——SSH 终端提示会话结束并可一键重连，SFTP / FTP 自动清理会话并提示"连接已断开"。（间隔可在设置中调整，0 表示关闭）

- **设置与快捷键**：侧边栏底部「设置」页（配置存数据库 settings 表，可随时扩展新配置）：
  - 常规：连接保活间隔、进程管理自动刷新间隔、终端字号（即时生效）
  - 快捷键：点击快捷键标签即可重新绑定（Esc 取消），冲突检测、一键恢复默认；默认快捷键：Ctrl+1~4 切换页面、**Ctrl+5 打开文档管理**、**Ctrl+6 打开站点管理**、Ctrl+T 新建 SSH 会话、Ctrl+W 关闭当前终端标签、Ctrl+B 开关终端信息面板、**F12 打开调试工具（DevTools）**；输入框 / 终端中按键不会被拦截（功能键 F1~F12 除外）

- **主机密钥校验**：所有 SSH / SFTP 连接都通过 `known_hosts`（`%APPDATA%\spark\known_hosts`）校验主机密钥，未知 / 不匹配 / 吊销都会明确提示，杜绝静默的中间人风险。
- **凭据加密**：已保存连接的密码、私钥、密钥口令使用 AES-256-GCM 加密后写入 SQLite，密钥由本机标识（Windows MachineGuid）派生，数据库文件被拷贝到其他机器也无法解密；旧版明文数据首次启动时自动加密迁移。
